# M01 Core Flows

## FLOW-PROJECT
项目列表 → 选择项目 → 项目详情。

## FLOW-APIKEY
项目详情 → API Key → 查看列表/状态 → 创建动作入口 → 创建成功时一次性Secret展示。

错误、撤销、禁用、过期按已有业务状态表达；不新增恢复规则。

## FLOW-MODEL-POLICY
项目详情 → 模型权限 → 查看已授权/未授权模型 → 执行已有权限允许的管理动作。

## FLOW-USAGE
项目详情或主导航 → 调用记录 → 查看调用记录 → 使用x-request-id等已有追踪能力查看详情入口。

## FLOW-LOGICAL-MODEL / PROVIDER / CHANNEL
平台导航 → 对应列表 → 查看/管理当前Baseline允许的对象。

未明确的路由编辑规则标记DESIGN_CLARIFICATION_REQUIRED。
