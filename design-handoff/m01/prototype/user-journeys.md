# M01 User Journeys

## JOURNEY-ENT-01 企业项目接入与调用管理

工作台 → 项目/应用 → 项目详情 → API Key → 模型权限 → 调用记录。

目的：让企业用户围绕一个项目完成调用身份、可用模型和调用追溯的管理闭环。

本Journey不在Prototype阶段新增额度、计费或支付规则。

## JOURNEY-PLATFORM-01 平台模型供给管理

平台端 → Logical Model → Provider → Channel。

目的：让平台运营人员看到逻辑模型与上游供给对象的管理入口。

具体Channel选择、健康度、路由优先级等业务行为若Baseline未明确，不在本原型自行定义。
