# M01 前端资产复用矩阵

> 来源：项目负责人提供的既有 Vue 前端工程。本矩阵只依据实际工程文件审计，不把未读取内容补成事实。

## 总体结论

Frontend Mode：`BROWNFIELD_REFACTOR`

现有工程已经具备成熟的 Vue 企业后台基础，不应重新搭建。M01 采用“保持 Layout / 视觉 / 通用组件 / 权限 / HTTP / Store / Router / 测试体系，替换业务域”的方式。

| 资产 | 证据 | 结论 | M01动作 |
|---|---|---|---|
| Vue 3 + TypeScript + Vite | package.json | KEEP | 不换技术栈 |
| Element Plus | package.json | KEEP | 保持现有组件视觉 |
| Pinia | package.json、src/stores | KEEP | 延续Store模式 |
| Vue Router + 动态路由 | src/router/index.ts、dynamic-routes.ts | KEEP/ADAPT | 替换业务路由，保留路由机制 |
| Axios统一HTTP | src/api/http.ts | KEEP/ADAPT | 保留错误/trace处理，替换业务API |
| AppLayout | src/layouts/AppLayout.vue | KEEP/ADAPT | 保留侧栏、顶栏、标签页等整体布局；清理旧业务特例 |
| 全局视觉Token | src/styles/global.css | KEEP | 保持现有bq-*视觉语言 |
| BasePageHeader | src/components/base/BasePageHeader.vue | KEEP | 新页面继续使用 |
| BaseDataTable | src/components/base/BaseDataTable.vue | KEEP | 项目/API Key/Provider等列表复用 |
| PermissionButton | src/components/security/PermissionButton.vue | KEEP/ADAPT | 映射HA AI权限码 |
| PermissionGuard等安全组件 | src/components/security | KEEP/ADAPT | 保留前端能力控制；不能替代后端鉴权 |
| DashboardModule / ECharts | src/components/dashboard | KEEP/ADAPT | 换成调用量、费用、成功率、Provider健康等指标 |
| Loading/Error/Empty | BaseEmpty、TraceErrorAlert、DashboardModule | KEEP | 新页面必须覆盖 |
| TagsView / Watermark / Fullscreen | AppLayout、features | KEEP | 默认保持 |
| Vitest | package.json、vitest.config.ts | KEEP | 新业务补单测 |

| 旧路由中的大量业务映射 | src/router/index.ts | ADAPT | M01先建立HA AI路由，再渐进清理 |
| AppLayout中的成本/预算等特殊路由判断 | src/layouts/AppLayout.vue | ADAPT | 保留Layout，逐步抽离旧领域特例 |
| Tiptap / ExcelJS / XLSX 等能力 | package.json | UNKNOWN | M01无直接需求，不删除，后续按依赖审计 |
