# 既有前端资产复用规范

## 定位
项目负责人提供的既有 Vue 工程是 HA AI 前端改造基线。前端模式为 `BROWNFIELD_REFACTOR`，不是 Greenfield。

## 已识别的可复用基础
基于当前提供工程，优先复用 Vue 3、TypeScript、Vite、Element Plus、Pinia、Vue Router、Axios、ECharts、Vitest、Playwright，以及既有 AppLayout、全局样式、权限、HTTP、Dashboard 和页面状态处理模式。

## 复用分类
每个资产必须先标记：
- KEEP：直接保留；
- ADAPT：保持模式并替换业务内容；
- NEW：现有工程无对应能力且有 Baseline 支持，可新增；
- UNKNOWN：证据不足，先确认；
- REMOVE-LATER：确认无公共依赖后再删除。

## 默认策略
Layout、导航框架、全局视觉语言、通用组件、HTTP封装、权限模式、Store模式、Router机制和测试体系优先 KEEP/ADAPT。原业务页面、菜单、指标和领域 API 主要 ADAPT/REMOVE-LATER。

## 删除规则
删除旧业务前必须证明：
1. 没有被公共 Layout/组件/权限/路由引用；
2. 新业务替代已通过测试；
3. 删除不会破坏现有工程构建；
4. PR 中明确列出删除清单。

## 视觉边界
“AI平台”不等于必须改成深色、霓虹或大屏风格。未经批准，保持当前整体样式和交互语言，只改业务内容。
