# M01 前端开发任务包

## 企业端
- 项目列表/详情；
- API Key管理；
- 模型权限；
- 调用记录基础页。

## 平台端
- Logical Model；
- Provider；
- Channel基础管理。

## 开发方式
先基于OpenAPI Mock并行开发，后端接口完成后切真实API。

## 必测
API Key首次Secret展示、禁用、撤销、过期状态；Model Policy授权/未授权；403/404/409/500；Loading/Empty/Error；企业/项目数据范围。

## 回传
Commit SHA、PR、Build、类型检查、自动化测试、关键页面截图、真实API联调记录、已知问题、Baseline偏离。
