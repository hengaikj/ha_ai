# M01 后端开发任务包

## 目标
打通 Enterprise → Project → API Key → Model Policy → Logical Model → Provider/Channel → ProviderAdapter → `/v1/models`、`/v1/chat/completions`。

## 必做
- Maven真实构建；
- MySQL 8 / Redis真实开发环境；
- API Key SHA-256摘要鉴权，Redis miss回源MySQL；
- Key禁用/撤销/过期；
- Project Model Policy；
- Request/Attempt持久化；
- FakeProvider自动化测试；
- 首个Provider：`https://api.hengaikj.com/v1` 非流式真实联调；
- x-request-id追踪。

## 暂不做
Billing、Fallback、stream=true、支付宝、微信支付。

## 回传
使用《开发验证证据提交模板》，不得只回复“已完成”。
