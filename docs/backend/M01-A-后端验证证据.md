# BE-M01-A 后端验证证据

## 范围

本证据只覆盖 Memory Repository、FakeProvider、`GET /v1/models`、
`POST /v1/chat/completions`（`stream=false`）和 `x-request-id`。
MySQL、Redis、HengAi Provider 和生产就绪性均保持 `NOT_RUN`。

## A 路径隔离

- `Application` 仅在 `ha.gateway.persistence.enabled=true` 时读取持久化 Bean。
- 默认值为 `false`；关闭时始终使用 `GatewayService.demo()`，绑定内存 API Key、
  Model Policy、FakeProvider 和 Request/Attempt 内存记录。
- `GatewayControllerTest` 显式设置 `ha.gateway.persistence.enabled=false`，
  防止 B/C WIP Bean 影响 A 的 Spring 测试证据。
