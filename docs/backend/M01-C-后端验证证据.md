# BE-M01-C 后端验证证据

## 范围

本任务只覆盖 HengAi Provider 非流式适配器、上游错误规范化、Usage/响应证据和 Secret 日志保护。Billing、Fallback、Streaming、支付未实现。

## 实现证据

- `HengAiProvider` 使用配置的 Base URL 和 API Key 调用 `/chat/completions`，请求固定 `stream=false`。
- OpenAI 兼容响应解析 `id`、首个 choice 文本和 `usage`，平台响应返回 Usage。
- 上游 401/403、404、429、超时和无效响应分别转换为稳定的平台错误码；上游响应正文不进入异常消息。
- API Key 只从 `HA_HENGAI_API_KEY` 注入；代码没有日志输出 Authorization、请求体或上游响应体。
- 未配置凭证时继续使用 FakeProvider，避免测试和本地启动依赖真实 Secret。
