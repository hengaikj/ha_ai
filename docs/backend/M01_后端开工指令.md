# M01 后端开工指令

> 本指令可直接交给后端开发人员或其开发 AI/Codex 执行。

你现在负责“智行官企业 AI 聚合服务平台”M01 后端开发。全程使用中文沟通、提交说明、PR 描述、Review、业务注释、测试报告和变更说明；Java Package、类名、方法名、变量名、数据库表/字段、API Path 使用规范英文，不使用拼音命名。

## 一、开工前必须读取
按顺序读取：
1. `docs/00_开发团队从这里开始.md`
2. `docs/governance/Baseline与变更管理规范.md`
3. `docs/governance/Git与PR规范.md`
4. `docs/governance/安全与Secret规范.md`
5. `docs/backend/00_后端开发启动说明.md`
6. `docs/backend/后端开发执行Skill.md`
7. `docs/backend/M01_后端开发任务包.md`
8. `contracts/` 中与本任务有关的 OpenAPI / Database / Redis Contract
9. 当前 Engineering Handoff 中对应 Requirement / AC / Technical Baseline

如果仓库中某份正式 Contract 尚未导入，不得自行编造；明确标记缺失并报告。

## 二、工作目录与分支
在共享开发机使用独立 worktree，不与前端共用 checkout：
```text
/workspace/ha-ai/backend-worktree
→ feature/m01-slice01
```

后端代码统一放在：
```text
backend/
```

不得直接向 main 提交。

## 三、M01唯一目标
打通：
```text
Enterprise
→ Project
→ API Key
→ Project Model Policy
→ Logical Model
→ Provider / Channel
→ ProviderAdapter
→ GET /v1/models
→ POST /v1/chat/completions (stream=false)
→ Request / RoutingAttempt
→ x-request-id
```

首个真实 Provider Base URL：
`https://api.hengaikj.com/v1`

## 四、必须完成
- Java + Spring Boot + MyBatis-Plus 工程真实构建；
- MySQL 8、Redis真实连接；
- Java根包 `com.hengaikj.ai`；
- API Key完整Secret不落库，使用摘要鉴权；
- Redis API Key Context缓存，miss回源MySQL；
- Key ENABLED / DISABLED / REVOKED / expires_at规则；
- Project Model Policy；
- `/v1/models` 只返回当前Project授权模型；
- FakeProvider自动化链路；
- `ha_ai_request`、`ha_ai_routing_attempt` 持久化；
- 非流式 HengAi ProviderAdapter；
- 每次调用返回 `x-request-id`；
- Provider Credential不进入日志和普通查询响应。

## 五、本轮明确不做
- Billing / Ledger；
- Fallback；
- stream=true；
- 支付宝/微信支付；
- 未经批准的新业务规则。

## 六、技术红线
- MySQL表前缀 `ha_`；
- 所有业务表/字段中文 COMMENT；
- 金额/价格/费率 `DECIMAL(24,12)` / Java `BigDecimal`；
- 账务舍入 `HALF_UP`（本轮尚不实现Billing，但不得另定义规则）；
- Redis Namespace `ha:{env}:`；
- Secret不得进入Git、日志、PR、测试截图；
- 不得把行业惯例或参考项目实现写成已确认需求。

## 七、验证
至少提交以下真实结果：
- Maven Build命令、退出码；
- Unit Test结果；
- API Key禁用/撤销/过期测试；
- Redis miss → MySQL fallback测试；
- Model Policy授权/拒绝测试；
- FakeProvider成功/失败测试；
- `GET /v1/models` 实际请求结果；
- `POST /v1/chat/completions` FakeProvider结果；
- 有有效DEV凭证后再执行真实Provider测试；没有凭证写 `NOT_RUN`。

## 八、提交
Commit使用中文，例如：
```text
功能(gateway): 完成M01 API Key鉴权与模型权限链路
测试(provider): 增加FakeProvider成功和异常场景
```

完成后按 `docs/governance/开发证据提交模板.md` 回传，不允许只回复“已完成”。
