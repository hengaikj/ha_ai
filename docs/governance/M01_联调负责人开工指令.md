# M01 联调负责人开工指令

## 目标
在共享开发机上维护独立 `integration-worktree → develop`，负责前后端合并后的DEV集成验证，不直接替前后端修改其feature分支。

## 联调顺序
1. MySQL 8 + Redis；
2. 后端 Build/Test；
3. 前端 Build/Type Check/Test；
4. 前端 → 后端 → FakeProvider；
5. `GET /v1/models`；
6. `POST /v1/chat/completions` stream=false；
7. x-request-id → Request/Attempt追踪；
8. 有有效DEV Provider凭证后执行前端 → 后端 → HengAi Provider；
9. 真实Provider未执行时必须写 NOT_RUN。

## Gate
只有前端、后端各自证据和DEV E2E证据均满足M01任务要求，才提交M01 Milestone Review。联调负责人不得把单元测试PASS改写成E2E PASS。
