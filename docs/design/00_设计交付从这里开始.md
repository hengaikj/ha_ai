# 设计交付从这里开始

**Design Done 不等于设计稿图片完成。** 正式完成必须包含 Product Design、Prototype、UI/UX、完整页面状态、响应式规则、Design System/Token、开发视觉资源、Component Mapping、Page/State/Interaction Spec、Traceability 和 Design Handoff Gate。

## 资源原则
Button、Input、Table、Card、Dialog、普通布局等由现有组件与Token实现，不做无意义切图。Logo、品牌图形、特殊Icon优先SVG；复杂插画、吉祥物、特殊背景提供WebP/PNG等开发资源。

## Brownfield
已有成熟前端时先审计现有Layout、组件和Token，能KEEP/ADAPT的资产不得重复建设。HA AI当前为BROWNFIELD_UI。

只有机器检查与人工设计审查均满足时，才允许 `DESIGN_HANDOFF_READY = TRUE`。
